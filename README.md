# synthetic_data_for_lung_cancer_event_extraction
This repository is being prepared to accompany our manuscript on clinical event extraction from lung cancer progress notes using synthetic data derived from case reports.

The repository will include code, prompts, and documentation for constructing synthetic clinical documents, generating structured annotations, and evaluating fine-tuned language models for clinical event extraction.

This repository is currently under preparation. Materials will be added progressively as they are organized for public release.

Some datasets and annotations used in the study may not be publicly available due to copyright, redistribution, confidentiality, and collaborative research restrictions.
